# Exportación

Esta carpeta contiene los archivos exportados o generados a partir del proyecto LAN9696.

## Contenido

En esta sección se pueden guardar archivos utilizados para revisión, entrega o fabricación del proyecto.

## Archivos posibles


- Archivos de fabricación.
- Archivos Gerber.

## Descripción

Los archivos de esta carpeta no siempre son editables directamente, pero sirven como respaldo, documentación o material de entrega del diseño.

Esta carpeta ayuda a separar los archivos generados de los archivos fuente del proyecto.
