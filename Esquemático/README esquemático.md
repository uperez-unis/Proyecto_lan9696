
# Esquemático

Esta carpeta contiene los archivos relacionados con el diseño esquemático del proyecto LAN9696.

## Contenido

En esta carpeta se incluye el archivo editable del esquemático y su versión exportada en PDF para facilitar la revisión del diseño.

## Archivos esperados

- Archivo `.DSN`: proyecto editable en OrCAD Capture.
- Archivo `.PDF`: versión exportada del esquemático.

## Descripción

El esquemático representa las conexiones eléctricas principales del diseño, incluyendo el componente LAN9696, conectores, alimentación, señales de comunicación y demás bloques necesarios para el funcionamiento del circuito.

El archivo PDF permite revisar el diseño sin necesidad de abrir el proyecto directamente en OrCAD.
