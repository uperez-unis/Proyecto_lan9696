# Schematic

This folder contains the files related to the schematic design of the LAN9696 project.

## Content

This folder includes the editable schematic file and its exported PDF version to make the design review easier.

## Expected Files

- `.DSN` file: editable project in OrCAD Capture.
- `.PDF` file: exported version of the schematic.

## Description

The schematic represents the main electrical connections of the design, including the LAN9696 component, connectors, power supplies, communication signals, and the other blocks required for the operation of the circuit.

The PDF file allows the design to be reviewed without having to open the project directly in OrCAD.
