# Proyecto LAN9696 - Diseño Esquemático y Layout PCB

Este repositorio contiene los archivos principales del proyecto de diseño electrónico basado en el componente **LAN9696**.  
El proyecto fue desarrollado utilizando herramientas de Cadence, específicamente **OrCAD Capture** para el diseño esquemático y **Allegro PCB Editor** para el desarrollo del layout de la PCB.
