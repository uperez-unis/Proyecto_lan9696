# Librerías

Esta carpeta contiene las librerías utilizadas en el proyecto LAN9696.

## Contenido

Aquí se pueden incluir símbolos, footprints y archivos auxiliares necesarios para abrir correctamente el esquemático y el layout PCB.

## Archivos 

- Footprints de Allegro, como archivos `.DRA`, `.PSM` y `.PAD`.
- Librerías personalizadas utilizadas durante el diseño.

## Descripción

Las librerías son necesarias para que los componentes del esquemático y del layout puedan visualizarse y editarse correctamente en Cadence.

Se recomienda conservar estos archivos dentro del repositorio para evitar problemas al abrir el proyecto en otra computadora.
