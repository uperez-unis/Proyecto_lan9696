# Layout PCB

Esta carpeta contiene los archivos relacionados con el diseño físico de la tarjeta PCB del proyecto LAN9696.

## Contenido

Aquí se almacena el archivo principal del layout desarrollado en Allegro PCB Editor.

## Archivos esperados

- Archivo `.BRD`: diseño editable de la PCB en Allegro.

## Descripción

El layout PCB incluye la ubicación de componentes, ruteo de señales, conexiones de alimentación, planos, vías y demás elementos necesarios para representar físicamente el circuito diseñado en el esquemático.

Este archivo permite revisar y modificar el diseño de la tarjeta dentro de Allegro PCB Editor.
