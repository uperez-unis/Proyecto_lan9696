# PCB Layout

This folder contains the files related to the physical PCB design of the LAN9696 project.

## Content

This folder stores the main layout file developed in Allegro PCB Editor.

## Expected Files

- `.BRD` file: editable PCB design in Allegro.

## Description

The PCB layout includes the component placement, signal routing, power connections, planes, vias, and other elements required to physically represent the circuit designed in the schematic.

This file allows the board design to be reviewed and modified inside Allegro PCB Editor.
